# The acceleration condition: "it should be speeding UP at the edge".
#
# The user asked for two things:
#   1. the gate should require a POSITIVE forward acceleration above a settable
#      value, not merely a speed — so a constant-speed sweep does not wrap;
#   2. with impact mode OFF, sweeping continuously across an edge must not
#      produce repeated wraps (that part is gate-off-churn.txt).
#
# Run: build/cw_devshell.exe run tests/scenarios/acceleration.txt
#
# Why `hand` and not `move`: `stroke` divides a line into EQUAL steps, which is
# constant speed by definition, and hand-written `move` lines cannot model a
# driver's integer pixel quantisation at 1000 Hz. `hand` ramps the speed linearly
# at a real report rate and quantises exactly like a mouse. The numbers below are
# measurements from this build, not guesses.

monitor 0,0,1920,1080
set mode both
set band 400
set guard 20
set speed 700
set impactGate on

# --- acceleration OFF: a fast constant sweep wraps (the old behaviour) -----
set accel 0
expect wrap
hand 1200 3000 3000 125 2000

# --- acceleration ON: the SAME constant sweep is refused -------------------
# This is the user's complaint: fast, but not speeding up. Measured at 0.
set accel 500
expect no-wrap
hand 1200 3000 3000 125 2000
expect no-wrap
hand 1200 3000 3100 1000 2000

# --- acceleration ON: a genuinely accelerating flick wraps -----------------
# A hand that ramps 800 -> 3000 px/s into the edge reads ~1750 px/s², three
# times the floor.
set accel 500
expect wrap
hand 1200 800 3000 125 2000

# The same shape at 1000 Hz must behave the same way: the reading must not
# depend on the report rate, which it did before this was fixed.
expect wrap
hand 1200 1000 6000 1000 2000

# --- acceleration ON: braking into the edge is refused ---------------------
# Fast far out, decelerating on arrival: the sign is negative, so the floor
# rejects it whatever its magnitude. The speed at the edge is also under the
# floor here, so both conditions agree.
set accel 500
expect no-wrap
hand 1200 6000 400 1000 2000

# --- the floor is settable, and a raised floor refuses a mild ramp ---------
# The same mild ramp passes at 500 and is refused at 3000: the setting is what
# the user tunes, and it has to actually move the decision.
set accel 500
expect wrap
hand 1200 1000 4000 500 2000
set accel 3000
expect no-wrap
hand 1200 1000 4000 500 2000
dump
