# v0.1.0

## 下载 · Download

使用本版本 Release 附件 `ra9fael.cursorwrap-0.1.0.wsplugin` 与旁边的 `.sha256` 文件
（`Get-FileHash <文件> -Algorithm SHA256`）。Win顺 0.22.0 或更新版本：设置 → 插件 →
已安装 → 添加插件 → 压缩包；安装后在列表里打开开关并确认 `ui` 权限。
Download the package and checksum from this release; install through
Settings → Plugins → Installed → Add plugin → Archive (.zip / .wsplugin), then enable
the plugin in the list and confirm the `ui` permission.

## 新功能 · What's new

- 多显示器光标回绕：光标推到布局最外层的外边时，从对边重新出现。算法移植自
  PowerToys CursorWrap（MIT）：边拓扑、内边不介入、非重叠区投影、50px 防震荡。
- Multi-monitor cursor wrapping: pushing the pointer off an outer edge of the display
  layout brings it back from the opposite edge. The algorithm is ported from PowerToys
  CursorWrap (MIT): edge topology, inner edges left alone, non-overlap projection and
  a 50 px anti-oscillation guard.
- 三种回绕方向（双向 / 仅上下 / 仅左右）与三种激活方式（总是 / 按住 Ctrl / 按住 Shift）。
- Three wrap directions (both / vertical / horizontal) and three activation modes
  (always / while Ctrl is held / while Shift is held).
- `cursorwrap`（`wrap` / `环绕`）关键字：留空看状态，Enter 开关、Ctrl+Enter 切模式、
  Shift+Enter 复制诊断。
- The `cursorwrap` (`wrap`) keyword: an empty query shows the status row; Enter
  toggles, Ctrl+Enter cycles the mode, Shift+Enter copies diagnostics.
- 显示器热插拔 / 分辨率变化后 500ms 防抖重建拓扑；布局缝隙写进诊断。
- The topology rebuilds with a 500 ms debounce after display hot-plug or resolution
  changes; layout gaps are reported in the diagnostics.

## 改进与修复 · Improvements and fixes

- 首个版本，无修复项。设置值非法（类型错误、越界、NaN/Inf）一律回落默认，不报错。
- First release, nothing to fix. Invalid settings (wrong type, out of range, NaN/Inf)
  always fall back to the defaults instead of erroring.
- 本地验证：43 项单元测试 + 7 个布局 fixture、32 项协议往返检查、L0 静态校验与完整
  JSON Schema 校验、真实宿主加载（钩子安装、常驻 6.6 MB、干净退出）、真机单屏手势
  （推右边缘落 (0, 536)、推左边缘落 (1919, 540)）。
- Local validation: 43 unit tests plus 7 layout fixtures, 32 protocol round-trip
  checks, L0 static validation with the full JSON Schema check, real-host loading
  (hook installed, 6.6 MB resident, clean exit) and real single-display gestures
  (pushing off the right edge lands at (0, 536), off the left edge at (1919, 540)).
