与 Win32 实现的对应关系

真机不引 Qt，窗口仍是纯 Win32，本稿所有效果均按「能落地的 Win32 等价物」设计：

稿件元素实现
窗口圆角 8pxDWMWA_WINDOW_CORNER_PREFERENCE = DWMWCP_ROUND
Mica / Acrylic 背景DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_MAINWINDOW / DWMSBT_TRANSIENTWINDOW（与宿主 WindowEffects.cpp 同一 API）
暗色标题栏 / 文字DWMWA_USE_IMMERSIVE_DARK_MODE，跟随系统 AppsUseLightTheme
系统强调色读 HKCU\...\Themes\Personalize 的 AccentColor（与宿主 SystemTheme 同源），暗色下按 1.55 提亮（对齐 Look.qml）
行卡片 / 分区owner-draw 静态区：card 底色 = 层色叠 Mica，发丝线 = 1px stroke 色
数值输入框owner-draw EDIT：去边框、上圆角、2px 下缘线，聚焦变 accent——Fluent 文本框特征
开关（toggle）owner-draw BUTTON：胶囊轨道 + 圆形滑块，开态填 accent；替代原 BS_AUTOCHECKBOX
accent 按钮 / 次级按钮owner-draw：实心 accent / 层底 + 发丝描边，hover/press 两态
加速度「关闭」开关即 0：开关关闭时数值输入禁用，语义与 1.0.0 的「关闭」勾选一致

交互语义（不变的部分）

逐行「应用」保留：数值仍是显式应用而非输入即生效；「采用建议值」必须按按钮；「恢复默认调参」恢复 6 个数值与加速度开关。宿主卡片摘要条只读，入口在设置卡。

布局变化

从 6 行平铺改为 4 个分区卡片（测量 / 门槛与判定 / 加速度 / 可视化），窗口更窄更高（460px），与 Win顺 设置页的分组样式一致；三个可视化开关从勾选框改为 Fluent 开关。
